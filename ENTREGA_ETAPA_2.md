# Ryuka Manager — Etapa 2

## Nuevo módulo: Compras

- Registro de compras de filamento.
- Creación automática de una bobina por cada unidad comprada.
- Distribución automática del precio total entre las bobinas.
- Registro de compras de insumos generales.
- Stock acumulado de argollas, cajas, stickers, imanes y otros insumos.
- Costo unitario promedio ponderado por insumo.
- Alertas de stock mínimo para insumos.
- Historial de compras y gasto mensual.

## Instalación

```powershell
npm install
npm run build
npm run dev
```
